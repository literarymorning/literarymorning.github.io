# The Literary Morning (문학 조간)

매일 아침 9시 무렵 발행되는 문학 소식 브리핑.
소설 공모와 당선 결과, 지원금·레지던시, 신간·서점가, 칼럼·서평, 문단 이슈, 해외 문학을 싣는다.

- `index.html` 페이지
- `index.json` 모든 호의 목록(최신 호가 맨 앞)
- `issues/YYYY-MM.json` 한 달치 호를 날짜별로 묶은 파일
- `requests.json` 비정기 스페셜 ‘이 작가가 궁금하다’ 요청 대기열
- `craft-log.json` ‘쓰는 사람’ 꼭지(창작 에세이·인터뷰. 월·수·금, 그리고 공모·신간·칼럼·이슈 소식이 하나도 없는 화·목·토·일)의 출처 목록과 소개한 글 기록

## 이 작가가 궁금하다

`requests.json`의 `writers`에 요청을 하나 더하면 다음 날 아침 호 맨 앞에 그 작가 소개가 실린다. 하루에 한 사람씩, 먼저 들어온 요청부터 싣는다. ‘쓰는 사람’ 꼭지가 실리는 월·수·금에는 싣지 않고 화·목·토·일에만 싣는다. 화·목·토·일에는 이 스페셜이 대체 ‘쓰는 사람’ 꼭지보다 먼저다.

```json
{"name": "작가 이름", "hint": "동명이인을 가를 단서(대표작, 국적 등, 없으면 생략)", "focus": "특히 궁금한 점(없으면 생략)", "requestedAt": "YYYY-MM-DD", "notBefore": "이 날짜 전에는 싣지 않음(YYYY-MM-DD, 없으면 생략)", "status": "pending"}
```

실리면 `status`가 `done`이 되고 `publishedIn`에 실린 날짜가 적힌다. 작가를 특정하지 못하면 `failed`와 `reason`이 적힌다.
